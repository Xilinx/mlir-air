# Repository installation and clients

## Project instructions

The repository maintains one shared [AGENTS.md](../AGENTS.md) and no
`CLAUDE.md`. Codex loads the applicable `AGENTS.md` files at session start.
Claude Code supports direct `AGENTS.md` loading from v2.1.277; v2.1.281 or later
also covers provider and telemetry configurations that lacked support in the
initial versions. See the official [Codex instructions guide](https://learn.chatgpt.com/docs/agent-configuration/agents-md)
and [Claude Code instructions guide](https://code.claude.com/docs/en/memory#agents-md),
checked 2026-10-27.

Claude's default **Project instructions** mode loads `AGENTS.md` when there is
no applicable `CLAUDE.md`, `.claude/CLAUDE.md`, or `CLAUDE.local.md` in the working
directory or its ancestors. If your local setup includes one of those files,
choose `claude-md-and-agents-md` under `/config` → **Project instructions** to
load both. This requires the built-in AGENTS.md support to be enabled. Older
clients should be upgraded; explicitly asking the agent to read `AGENTS.md`
also provides its contents for an individual task. The repository does not
modify user settings.

Project instructions and skill discovery are separate: sharing `AGENTS.md`
does not make Claude scan `.agents/skills`. The two skill registrations below
remain necessary for the documented discovery paths.

## Skill discovery

The canonical payload is `agentic`. Tracked `.agents/skills/<name>/SKILL.md` and `.claude/skills/<name>/SKILL.md` entries contain discovery metadata and a relative link to the canonical skill. They are generated by `tools/sync_package.py`; edit the canonical payload and regenerate. Ordinary files work on Linux and Windows without symlink privileges. No global client settings, permissions, model choice or reasoning effort are changed.

Launch the client from the repository root or a model directory. Name `deploy-new-llm` in the request. The client reads that entry and follows its canonical link; load detailed references as needed. If it does not discover a skill, supply the explicit canonical SKILL.md path. Repository instructions and user requests retain their normal precedence. Reading a registration is distinct from evidence that a session followed a skill; record actual exposure when studying agent behavior.

Codex scans repository `.agents/skills` up to the repository root and supports symlinked skill folders: [official skill documentation](https://developers.openai.com/codex/skills), checked 2026-10-26. Claude Code uses project `.claude/skills`: [official skill documentation](https://code.claude.com/docs/en/skills). The generated-file adapter avoids depending on symlink scanning. Old numbered phase skills are removed by this migration; the 17 canonical names replace them.

AIR toolchain setup, HF access, model weights and device scheduling remain normal deployment prerequisites. Follow the current [AIR integration](references/project-integration.md). The optional host source inspection reports missing interfaces; it is not a mandatory client startup checker. Starting a session does not require a clean directory, a particular client cache layout, or removal of unrelated session files.
