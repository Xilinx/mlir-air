# MLIR-AIR

MLIR-AIR is a compiler infrastructure for mapping AI workloads onto AMD NPUs
(Neural Processing Units) and Versal AI Engine arrays. It lifts loop-nest and
tensor programs into asynchronous, spatial dataflow through MLIR dialects —
placing compute on tiles, scheduling data movement, and generating optimized
binaries for AI accelerators.
