# MLIR Reference

The pages in this section document the operations and passes defined by
MLIR-AIR. They are generated by `mlir-tblgen` from the TableGen sources listed
below on every documentation build. The semantics of the `air` dialect are
specified in the [AIR Compute Model](AIRComputeModel.md); these pages document
the operation and pass interfaces.

| Page | Contents | Source |
|---|---|---|
| [AIR Dialect](AIRDialect.md) | Operations and types of the `air` dialect: the `launch` / `segment` / `herd` hierarchy, data movement, channels, and asynchronous tokens. | [`AIR.td`](https://github.com/Xilinx/mlir-air/blob/main/mlir/include/air/Dialect/AIR/AIR.td) |
| [AIR Transform Ops](AIRTransformOps.md) | `transform.air.*` operations, which expose AIR transformations to the MLIR `transform` dialect. | [`AIRTransformOps.td`](https://github.com/Xilinx/mlir-air/blob/main/mlir/include/air/Dialect/AIR/AIRTransformOps.td) |
| [AIR Transformation Passes](AIRTransformPasses.md) | Dependency analysis, tiling, placement, and buffering. | [`Transform/Passes.td`](https://github.com/Xilinx/mlir-air/blob/main/mlir/include/air/Transform/Passes.td) |
| [AIR Conversion Passes](AIRConversionPasses.md) | Lowering of `air` to MLIR-AIE, `airrt`, and the MLIR `async` dialect. | [`Conversion/Passes.td`](https://github.com/Xilinx/mlir-air/blob/main/mlir/include/air/Conversion/Passes.td) |
| [AIRRt Dialect](AIRRtDialect.md) | Host-side IR for the `launch` and `segment` bodies: segment and herd loading, L3 allocation, and DMA issue. | [`AIRRtOps.td`](https://github.com/Xilinx/mlir-air/blob/main/mlir/include/air/Dialect/AIRRt/AIRRtOps.td) |
